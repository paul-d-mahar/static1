# static1

A simple static website with HTML, CSS, and JavaScript, ready to be hosted on GitHub Pages.

## Features

- 📄 Modern HTML5 structure
- 🎨 Responsive CSS design with gradient backgrounds
- ⚡ Interactive JavaScript functionality
- 📱 Mobile-friendly responsive layout

## Viewing the Site

### Locally

To view the site locally, you can:

1. Open `index.html` directly in your browser, or
2. Use a local server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`

### GitHub Pages

To host this site on GitHub Pages:

1. Go to your repository **Settings**
2. Click on **Pages** in the left sidebar
3. Under **Source**, select your branch (e.g., `main`) and root folder `/`
4. Click **Save**
5. Your site will be available at `https://paul-d-mahar.github.io/static1/`
